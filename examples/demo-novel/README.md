# Demo Novel：雾港来信

这是一个完全虚构、可公开使用的脱敏示例，用来展示 Novel Codex Writer 的文件组织方式。

> 该目录不会被工作台自动识别为你的真实作品，也不会写入 `小说项目/projects.json`。它主要用于阅读、测试和演示。

## 示例包含

- `大纲/原始大纲.md`：未经整理的故事构想。
- `大纲/细纲_第001章.md`：第 1 章的目标、情节点与结尾钩子。
- `正文/第001章_雾港来信.md`：缩短版演示正文。
- `审查报告/第001章_审查报告.md`：S1-S4 审查示例。
- `章节提交/第001章_commit.md`：章节完成后的结构化变化记录。
- `章节提交/chapter-001-v1.memory_patch.json`：结构化记忆补丁示例。
- `记忆库/current/`：下一章仍然需要知道的当前状态。

## 如何使用

1. 先浏览这些文件，理解一章从大纲到记忆更新的完整链路。
2. 在本地工作台新建一本小说。
3. 将本示例中的内容复制到新小说对应目录中进行试验。
4. 不要把真实小说正文提交到公共仓库；真实作品应保存在被 `.gitignore` 忽略的 `小说项目/作品/` 中。

## 说明

演示正文为了便于阅读被刻意缩短，不满足项目默认的 2000–2500 字正式章节要求，因此不要把它当成章节质量标准。
