# Novel Codex Writer v0.1.0

首个面向公开体验的版本。

Novel Codex Writer 是一个本地优先、作者可控的 AI 长篇小说创作工作台。它不追求“一句话生成整本小说”，而是把长篇创作拆成可检查、可回退、可持续的章节工作流。

## 版本亮点

- 多作品创建、切换、重命名和本地管理。
- Markdown 大纲、正文、审查报告和档案管理。
- Codex `webnovel-writer` Skill。
- “章节细纲 → 写作任务书 → 正文 → 审查 → 章节提交 → memory patch”闭环。
- `current`、可重建索引、历史档案和篇章 snapshot 分层记忆。
- DeepSeek 快速审校与 Codex 深度审校入口。
- 完全虚构的《雾港来信》脱敏 Demo。
- 中英文主页、贡献指南、安全说明和 Issue / PR 模板。

## 安全与可靠性

- `.env`、会话缓存、日志和构建产物默认不进入 Git。
- `小说项目/projects.json`、用户作品和回收站默认不进入公共仓库。
- `activeProjectId` 被限制在 `小说项目/作品/` 内，阻止 `../` 路径逃逸。
- GitHub Actions 自动编译全部 Python 源码并运行测试。
- 功能测试覆盖：
  - memory patch 字段和状态校验
  - 重复记忆 ID 拒绝
  - Markdown 记忆索引重建
  - 索引删除后恢复
  - 活动作品目录隔离
  - memory patch 幂等执行
  - 同一 patch ID 内容冲突检测

## 快速开始

### 环境

- Windows 10 / 11
- Docker Desktop
- 可选：Codex App / Codex CLI
- 可选：DeepSeek API Key

### 获取项目

```powershell
git clone https://github.com/damingishere-coder/novel-codex-writer.git
cd novel-codex-writer
```

然后按照仓库中的 [快速开始](../quick-start.md) 启动本地工作台。

## 当前限制

- 主要启动流程面向 Windows + Docker Desktop。
- Codex 与 DeepSeek 均为可选能力，输出质量取决于模型和作者资料。
- 自动审查不能替代作者判断。
- 项目强调人工确认，不提供无人值守批量生成整本小说。
- macOS、Linux、一键备份和完整导入导出尚未完成。

## 升级与数据保护

- 升级前建议备份整个 `小说项目/`。
- 不要只备份 `memory_index.json`，索引可以重建，Markdown 才是事实源。
- 不要把真实 API Key、登录缓存或未公开正文提交到公共仓库。
- 旧项目迁移前先使用副本执行 `memory_doctor.py --migrate-legacy --dry-run`。
