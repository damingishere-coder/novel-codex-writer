# 真实连续 10 章验收清单

这份清单只记录流程结果和脱敏故障，不复制正文、人物名、剧情、密钥或绝对私人路径。验收必须使用 `Novel-Codex-Writer/小说项目/` 中同一本真实小说；测试数据不能代替作者试写。

## 开始前

- 使用根目录 `启动网页.bat`，确认地址为 `http://127.0.0.1:5174/`。
- 打开“启动预检”，确认没有必要阻断项。
- 确认顶部显示正确作品、目标章节、六步进度和一个唯一主按钮。
- 在工作台执行一次 ZIP 导出，并妥善保存在 Git 忽略范围内。

## 每章必须观察

- 打开项目后 10 秒内能理解唯一下一步，无需判断该运行哪个脚本。
- 正文、审查或来源 revision 变化后，旧任务书、审查、提交或 patch 会被标记过期。
- 创作、正文修改、应用 patch 和版本恢复都有作者确认；安全诊断可直接执行。
- 动作完成后状态自动刷新并打开对应产物；如果当前草稿未保存，则保留现场并提示稍后打开。
- 没有丢稿、跨小说读取、错误章节写入、静默覆盖或真实 Provider 误调用。

## 通过标准

- 10/10 章完整最终化。
- 至少 8/10 章无需开发者介入排错。
- 所有阻断都有可执行恢复说明。
- 私人内容未进入 Git、测试、日志或问题报告。

若未通过，只登记“发生在哪个步骤、错误代码、脱敏复现条件、是否可恢复”。修复真实阻断后，从当前章节继续，不重做已最终化章节。
