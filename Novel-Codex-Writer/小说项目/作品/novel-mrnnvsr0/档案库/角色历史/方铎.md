# 角色档案：方铎

- 身份：曜石集团前期执行者与贸易代表。
- 行为逻辑：不是临时降智的坏人，而是真正把新人死亡、高风险实验和团队失败当成可计入收益模型的人。
- 第024—029章争夺铜帽废市的贡献、账本与结算归属，并为增加 Boss 结算价值将锯齿祭司喂到 C 级。
- 第049—051章代表曜石规模化复制林序的盐贸易路径，事故后销毁批次记录并继续销售。
- 第072—084章在潮骨病巢销毁实验证据，第084章杀死准备作证的屠岸，并将律法碎片植入心脏形成掠夺领域。
- 第089章掠夺领域被无偿救援、托管、债务抵消与无主物转移制造的无法结算账目拖垮，方铎与领域一同崩溃死亡。
- 方铎死亡不等于曜石集团倒闭。
