# 章节写法参考

这是一组可选工具，不是章节模板。写作时不必逐项套用，也不要求每章达到同一种节奏。

## 一、章节最小骨架

多数章节只需处理好三件事：

1. 人物此刻想完成什么；
2. 人物为此做了什么；
3. 行动之后，局面发生了什么变化。

三者不必平均分配篇幅，也不必全部在开头讲明。变化可以是危险、信息、关系、利益、资源、位置、身份、情绪或下一步目标。

## 二、几种灵活写法

以下结构可以单独使用，也可以互相混合。

### 行动与危机

出现问题 → 作出判断 → 尝试解决 → 承担结果。

重点是行动清楚、因果成立。成功可以完整，也可以只是争取到时间或退路。

### 调查与探索

产生疑问 → 获得线索 → 验证或误判 → 形成新的判断。

不必每章揭开答案，但应让读者比开头多知道一点，或意识到原来的理解有问题。

### 交易与博弈

双方各有所求 → 试探条件 → 交换筹码 → 达成、破裂或留下后手。

重点不在复杂条款，而在人物真正想要什么，以及交易怎样改变处境。

### 人物与关系

共同经历一件事 → 立场发生碰撞 → 有人作出选择 → 关系出现细微或明显变化。

对话章也可以有推进，推进未必依靠冲突升级。

### 过渡与日常

处理上一阶段后果 → 展示人物状态或世界变化 → 准备下一目标。

过渡章不等于无事发生。一次休息、一顿饭、一段赶路，也可以完成疗伤、分配、试探、告别或决定。

### 高潮与兑现

前期积累集中碰撞 → 人物作出关键选择 → 主要矛盾得到阶段结果 → 新后果扩散。

高潮可以是战斗、逃亡、交易、揭密、营救、结算或关系决裂，不必统一写成击败强敌。

## 三、开头与结尾

- 开头从最适合当前章节的位置进入，可以承接动作、抛出问题、展现日常，也可以先建立气氛。
- 无须强制在固定字数内制造危险或反转，但不宜长时间让读者找不到当前关注点。
- 结尾可以停在发现、选择、结果、悬念或情绪余味上。
- 不要求每章都用强钩子。阶段收束时，让读者获得满足感同样有效。
- 钩子之后通常不再追加解释性总结，以免削弱力度。

## 四、节奏与信息

- 一个场景如果推动了事件、揭示了人物、提供了必要信息或为后文蓄力，就有保留价值。
- 重要场面可以写足，不必为了赶节点匆忙跳过；次要过程则可以直接概括。
- 设定解释尽量跟随疑问、行动和后果出现，避免连续大段介绍背景。
- 铺垫不必当章兑现，兑现也不必每次都很大；只要前后能够连接，读者回想时觉得合理即可。
- 同一种冲突、反转、面板提示或结尾方式连续出现时，注意适当变化。

## 五、设定与细纲的关系

- 不可违背的事实、核心设定和连续性高于临场发挥。
- 章节细纲规定主要目标和关键结果，不必限制每一步过程。
- 如果写作时出现更自然的行动、对话或场景，可以调整顺序与实现方式，并同步处理后续衔接。
- 具体人数、时间、等级、伤势、物资和规则以当前设定库、时间线和章节规划为准，本文件不重复列举。

## 六、写完后快速问五句

1. 这一章最主要写了什么？
2. 人物是否真正做出了选择或行动？
3. 开头与结尾相比，有什么发生了变化？
4. 哪一处最值得读者记住？
5. 是否有内容只是在重复解释，却没有增加画面、人物或推进？

能回答前四句，并清理第五类内容，这一章通常就已经成立。
