# 第003章 memory_patch

## 新增

- 食盐解释条件：靠近新鲜血时“腐血狂暴饵”增强；处于干燥、离血环境并先接触腐肉时“驱秽净化粉”增强。
- 小样证据：盐灼伤断爪与伤犬；盐粒滚入新鲜血后白火熄灭并强化猎犬。
- 镜像征兆：章末“驱秽净化粉”说明变淡，暂不得正式命名镜像校正。
- 价值差：只有在可复现前提下，一小袋净化盐才可能换一张技能卷轴。

## 更新

- 人数：章初10人；陈放与郭兰确认死亡；章末8人生还。
- 林序：首次主动用解释可视破局，观察性头痛持续；仍无职业、无魔力、无主动稳定。
- 赵峥：右腿外侧撕裂伤，已由苏禾压迫处理；正式公开一级登记冒险者身份。
- 苏禾：负责止血、伤员转移与三分钟医疗边界。
- 何驿：参与推车、搬盐和撤退；刘原以装修经验处理钢网；袁宁记录位置、用量、伤亡与批次。

## 资源变化

- 两袋盐已开封并用于小样、盐雾与意外散落；后续不依赖精确余量。
- 钢网局部变形，手推车纸箱被犬爪抓破，钢索承受冲击后需检查磨损。
- 手机、电器、食品与药物继续隔离。

## 移除或替换

- 当前物资来源统一为坍缩范围内可移动归属物。
