# 《我靠工业垃圾打穿地下城》总纲（长篇重构版）

> 本总纲只规划前十篇、300章的第一阶段，不设定全书完结篇数。第300章完成“林序升至15级并正式获知位面战争真相”的阶段转折，后续继续进入位面战争、候选者争夺与造神阶段。

## 一、作品定位

- 题材：现代地下城、异界冒险、独行者生存、道具流、位面贸易、社会异化、神眷悬疑、位面战争。
- 主视角：第三人称限知，始终紧贴林序；宏观社会变化通过价格、法规、案件、交易和个人遭遇呈现。
- 基本气质：冷峻、克制、写实。组织和人物各有立场，不以单一坏人解释所有黑暗。
- 网文体验：快节奏、强危机、有效升级、装备组合、价值差交易、反追杀与阶段性暴富。
- 第一阶段体量：10篇、50节、300章；每篇约30章，每章建议2200—2800字，预计66—84万字。
- 长篇边界：第一阶段不解决诸神、魔网和位面战争，只完成从普通人到15级传说冒险者的成长。

### 一句话卖点

别人靠职业和法术闯地下城，五金店老板林序却以【游侠·陷阱专家】和【行商人】的普通职业，激活本不该属于他的魔法道具，再把现实废料、工业结构和异界奇物拼成只属于自己的装备体系。

### 一句话主题

当地下城成为现代社会的新边疆，人类会把职业、神迹、异族和登神机会变成怎样的新权力与新生意？

## 二、世界开端

十五年前，全球随机出现“裂缝”。裂缝连接的不是游戏空间，而是真实存在的异位面、文明、城市、遗迹和战争前线。

人类进入裂缝后会获得个人面板和地下城任务，但新人面板的职业栏最初是【未定】。系统会结合六维属性、实际行为、团队职责和关键选择，在Lv.1—5的入门阶段逐渐形成职业倾向、核心职业与变种分支。地下城资源、道具和交易所得不能被直接捡回现实，必须先进入待结算记录，再在通关或满足脱离条件后由系统面板发放；攻略失败，裂缝会在倒计时结束后“翻转”，使地下城生物、环境和规则泄漏到现实。

十五年里，人类已经围绕裂缝形成新的国家机构、冒险者协会、财团、保险、鉴定、医疗、装备、黑市和情报产业。但不同位面的物质解释、魔法规则和种族制度差异巨大，过去的经验并不能保证下一次安全。

公众把冒险者视为一夜暴富的新阶层，却很少看见低级地下城里无法统计的失踪者、被公司买断的职业者、被队友杀死后无法取证的尸体，以及被当成战略资产管理的高阶冒险者。

林序，29岁，城乡接合部五金店老板，副业是几乎无人阅读的地下城漫画《规则之下》。他羡慕冒险者一次通关改变命运，却也清楚绝大多数普通人连入口都活不过。

一道E级裂缝突然吞掉他的五金店、公交站和三十名路人。手机变成会爆炸的“雷囊”，食物成为毒物，现实常识开始失效；林序则看见了物资在当前位面中的解释倾向。

他用九块九的盐逼退腐尸猎犬，用货架、钢索和工业废料布置陷阱，却在第一次陷落中付出惨重代价，只完成紧急脱离。结算面板发给他一枚按理只能由牧师使用的损坏指环；仍处于【职业：未定】状态的林序，却让指环亮了起来。此后，他通过一次次入门地下城，才逐渐形成主职业【游侠·陷阱专家】与副职业【行商人】。他的职业始终没有施法能力，魔网却允许他激活法师、牧师、邪术师乃至异族血脉限定的魔法道具。

魔网没有拒绝他。

从这一刻开始，他先为了赚钱进入地下城，随后为了不被国家、财团、教会和法师组织控制或拆开研究而变强。直到15级，他才正式确认：裂缝、地下城、人数限制和冒险者升级，都只是位面战争开始前的筛选；战争真正争夺的，是有限的登神名额。

## 三、地下城时代的人类社会

### 1. 国家视角

- 裂缝兼具国境、灾害源、矿区、军事设施和未知外交口岸属性。
- 国家管理部门负责登记、隔离、战利品审查、异界检疫、入口许可和翻转响应。
- 军方关注异族军力、战略道具、永久通道与高等级冒险者的忠诚。
- 高等级冒险者仍是公民，但出境、装备交易和进入外国裂缝会受到限制。
- 国家内部并非单一立场：安全、经济、科研、外交和地方政府会争夺管理权。

### 2. 市场与资本

- 入口资格、地下城情报、职业培训、道具鉴定、尸体回收和治疗资源都已产业化。
- 财团承担高额探索成本，因此要求战利品优先权、雇员职业归属和长期债务合同。
- 地下城产出价格剧烈波动，同一件物品可能同时是药物、军品、宗教圣物和违禁品。
- 冒险者可一夜暴富，也可能因装备贷款、治疗费用和任务违约终身负债。
- 黑市交易绑定装备、身份名额、尸体、地图、职业药剂和未经检疫的异界生物。

### 3. 地下城法律灰区

- 现实法律原则上仍适用，但取证、管辖、异族人格和任务强制导致执行困难。
- 队伍内部常用魔法契约、公司合同和战利品协议替代法律。
- 录像设备可能因位面解释失效，活着回来的人往往掌握叙事权。
- 高价值战利品会诱发队友相残、伤员遗弃、情报隐瞒和蓄意提高任务难度。
- “进入地下城等于自愿承担风险”成为公司和组织逃避责任的常用话术。

### 4. 社会阶层变化

- Lv.1—5的职业定型成为新的阶层分流与跃迁通道，培训机构、企业和国家都试图提前影响新人的职业选择。
- 施法职业、治疗职业和稀有血脉拥有更高社会议价权。
- 生活职业和低阶物理职业常被视为消耗品。
- 高阶冒险者形成事实上的超凡精英阶层，能够影响企业、城市和国家决策。
- 普通人既崇拜冒险者，也恐惧职业者拥有超出法律执行能力的暴力。

## 四、职业体系

### 1. 战斗职业三大力量体系、12个核心职业

#### 奥术使用者

- 法师：后天学习魔网公式与咒语。
- 术士：依靠血脉天赋获得魔力。
- 邪术师：与高等存在签订契约换取力量。
- 吟游诗人：以艺术、语言和表演引导魔网。

#### 神术使用者

- 牧师：作为神灵代理获得神力。
- 德鲁伊：从自然与生态誓约中获得力量。
- 圣武士：通过信条和誓言激发神圣力量。
- 游侠：以追踪、狩猎、荒野技巧为主体，部分分支使用微弱自然神术。

#### 物理／技巧战斗者

- 战士：武器、护甲和正面战斗专家。
- 野蛮人：依靠愤怒、体魄和原始力量。
- 游荡者：依靠潜行、技巧、情报和弱点攻击。
- 武僧：依靠气、身体控制和徒手格斗。

### 2. 变种职业

核心职业会根据力量来源、训练路径、神祇、血脉和战斗方式产生变种。变种不是单纯换名，必须改变技能、装备、成长代价和组织归属。

职业不是入场即随机发放的身份标签。Lv.1—2主要积累行为记录并出现若干职业倾向；Lv.3—4形成初步核心职业和副职业；Lv.5完成第一次定型，并根据此前最稳定的战斗方式开放相应变种。定型后仍可能转职或变异，但必须支付训练、资源、等级乃至信仰代价。

### 3. 副职业

副职业来自现实经历、生产方式和社会身份，不计入12个核心战斗职业。典型副职业包括行商人、工匠、药剂师、学者、矿工、医护、猎人和鉴定师。

副职业提供专业能力，不直接赠送战斗胜利。

### 4. 林序职业（Lv.5第一次定型后）

- 主职业：【游侠·陷阱专家】。
- 副职业：【行商人】。
- 职业形成：第一次地下城只记录侦察、诱导、陷阱和物资控制行为；Lv.2出现游侠／游荡者倾向；Lv.3形成【游侠】与【行商人】；Lv.5才正式定型为【游侠·陷阱专家】和【行商人】。
- 职业性质：非施法型游侠分支，在Lv.5定型时放弃自然神术成长，换取陷阱、追踪、地形、远程武器、危险感知和独行生存强化。
- 行商人能力：估价、货物管理、议价、路线记忆、风险核算。
- 战斗方式：不正面拼属性，依靠提前准备、地形、诱饵、陷阱、远程武器和魔法道具组合。
- 核心矛盾：职业面板明确显示他不是施法者，魔网却允许他激活职业和血脉受限的魔法道具。

## 五、种族与神明烙印

“上位、中位、下位”是诸神体系、位面战争和现实组织广泛使用的力量等级分类，不代表个体价值。种族神明的性格烙印会形成总体倾向，但不能抹掉个体、阶层、国家和派系差异。

### 1. 上位族

- 龙族：傲慢、贪婪、秩序；控制稀有资源、契约与价值体系。
- 构装体／发条文明：崇拜绝对尺度和逻辑，信仰【万物尺度·冈恩】的极端镜像。
- 天使族：绝对理性、排他性正义、规则偏执；常作为神意审查者和战争仲裁者。

### 2. 中位族

- 人类：野心、变数、多样性；真实神明渊源与魔法女神的实验有关，但前期并非公共知识。
- 精灵：敏捷、感知、长寿、审美与魔法艺术；内部存在贵族、工匠、自然教派与流亡者。
- 矮人：顽固、勤劳、器物传统；信仰【万物尺度·冈恩】，与发条文明对“尺度”的理解不同。
- 亡灵文明：追求永恒逻辑，信仰【灰烬主宰】，并非所有亡灵都敌视生命。
- 女妖／魅魔：诞生于魔网频率震荡，擅长情感、记忆和秩序寄生。

### 3. 下位族

- 哥布林／兽人：资源匮乏、战争化程度高，信仰【荒原战神】；所谓低智与暴虐既受神明烙印影响，也受长期被当成战争消耗品的制度塑造。
- 半身人／侏儒：乐天、技术狂热，社会地位低但对机械、结构和微型工艺敏感。
- 亚人／变种：鱼人、蛇人等，环境适应力极强，单项属性偏科，在各位面常遭受人格与公民资格争议。

### 1. 个人面板

基础属性以普通成年人的10点为参照。种族、职业、称号、装备和永久伤势均会影响属性，但属性不是唯一胜负条件。

### 2. 冒险者等级与评级

| 等级 | 常用评级 | 社会位置 |
| --- | --- | --- |
| Lv.1—2 | F级 | 职业倾向积累期，死亡率最高 |
| Lv.3—4 | E级 | 核心职业初步成形，仍处于定位修正期 |
| Lv.5—6 | D级 | 完成第一次职业定型，可受雇进入标准地下城 |
| Lv.7—9 | C级 | 城市级骨干，拥有稳定装备体系 |
| Lv.10—12 | B级 | 国家关注的高阶冒险者 |
| Lv.13—14 | A级 | 战略级个人，可影响入口与地区战局 |
| Lv.15 | S级／传说门槛 | 正式获得位面战争知情资格 |
| Lv.16—19 | 传奇 | 跨位面强者、神权代理或候选竞争者 |
| Lv.20 | 凡俗顶点 | 获得完整登神竞争资格，但尚未成神 |

### 3. 地下城任务面板

```text
地下城名称：
挑战等级：
当前挑战者：X/X
脱离条件：
攻略条件：
该地下城挑战次数：
距离地下城翻转：XX天XX小时
```

任务面板只显示被当前挑战者和位面规则共同承认的信息，不提供完整答案。高等级地下城可能隐藏、篡改或分裂任务条件。

### 4. 地下城进入与返回类型

- 陷落型：裂缝主动吞入人、建筑或区域。满足任务面板中的脱离条件后，挑战者可以从任何符合条件的位置通过面板直接脱离；脱离不等于通关，评价和奖励通常远低于完整攻略。
- 门型：挑战者主动穿过稳定或临时的现实之门。无论是否完成攻略，都必须活着返回指定门扉才能回到现实；Boss死亡不会自动传送挑战者。
- 复合型与高阶变种可以改变门的位置、分裂返回点或锁定部分挑战者，但必须在任务面板或可调查规则中留下信息。

### 5. 产出与结算规则

- 冒险者带入的现实装备可以在地下城中使用，损坏与消耗真实发生。
- 怪物材料、矿石、魔法道具和异族交易所得只形成待结算记录，不能直接装入背包带回现实。
- 副本内的环境物、任务物和机关可以被操作或消耗，但只有系统承认的归属与贡献，才会在脱离或通关后转化为个人奖励。
- 陷落型挑战者满足脱离条件并使用面板后立即结算；门型挑战者只有重新跨过现实之门才结算。未能返回者无法领取已经记录的产出。
- 因此，地下城内的人类冲突会集中在贡献判定、任务归属、队内合同、证词、结算份额和返回资格，而不只是抢夺尸体旁的掉落物。

## 七、林序的神眷异常

林序的魔法异常独立于【游侠·陷阱专家】和【行商人】，前期不在面板上直接显示“魔法女神眷顾”。

### 1. 位面解释可视

- 能看见现实物资在当前位面的两到三种解释倾向。
- 只显示倾向，不显示准确概率和标准答案。
- 环境、对象、使用方式、种族和地下城层级会改变结果。
- 林序必须通过小样、陷阱和低成本测试降低风险。
- 同一种物资被大量重复使用后，位面生态和敌人会学习适应。

### 2. 魔法道具合法使用

- 可以绕过部分职业、血脉、信仰和阵营使用限制。
- 能激活不属于游侠的法师、牧师、邪术师和异族道具。
- 不绕过等级、能量、材料、耐久、身体和灵魂消耗。
- 不能因此学习法术，也不会获得法术位。
- 高阶道具会增加魔网负载，使教会、法师和神权存在更容易发现他。

### 3. 赛博炼金

- 以现实工业结构承担瞄准、承压、散热、传动和安全冗余。
- 以魔法核心或道具提供能量和特殊效果。
- 必须满足材料、结构与效果的匹配，不能随意把两件东西粘在一起产生神器。
- 产品会磨损、过热、失控，需要维护和备件。

### 4. 硬件级豁免

- 对依赖职业识别、施法者标签和魔网权限的部分效果具有绕过能力。
- 不等于魔法免疫，高阶伤害、诅咒、精神污染和神术仍能伤害他。

### 5. 神眷真相

- 普通人认为他是稀有职业变种。
- 法师认为魔网对他的身份校验出现了异常放行。
- 教会内部有人视他为圣徒，有人视他为漏洞或亵渎。
- 林序直到中后期才确认自己的异常与魔法女神有关。
- 女神的动机不完全透明：她可能在保护他，也可能在培养、测试或利用一个不依赖施法职业的外部变量。

## 八、林序的人物原则与成长动力

### 1. 行为底线

- 首先保证自己的安全。
- 只做力所能及的事情。
- 风险可控时能帮就帮，不接受无限责任。
- 不为利润主动残害无辜。
- 对明确加害、追杀、绑架或实验自己的人杀伐果断。
- 动手前确认威胁，动手后处理证据、同伙和报复链。
- 不建立固定冒险小队或公会；可以临时合作、雇佣、交易和互保。

### 2. 三阶段动力

1. 赚钱：从小店老板变成真正有选择权的人，幻想一夜暴富。
2. 自保：异常暴露后，为抵抗国家征用、财团控制、教会审判和法师实验持续变强。
3. 战争：15级确认位面战争与登神竞争后，为避免自己和地球被他人决定命运而进入候选者战争。

### 3. 成长方式

- 等级和属性增长。
- 陷阱、追踪、远程武器与独行生存能力。
- 行商人的贸易、物流、估价和信用网络。
- 魔法道具收集、组合与赛博炼金。
- 情报、安全屋、备用身份和跨位面逃生路线。
- 对国家、财团、宗教、法师组织和异族政治的判断力。

## 九、主要人物与关系原则

### 林序

五金店老板、漫画作者、【游侠·陷阱专家】、【行商人】。不追求领导别人，重视退路、成本、证据和货物。人物弧光不是变成救世主，而是从只相信自己的库存，成长为能判断复杂利益并保持独立选择权的人。

### 苏禾

急诊护士，后觉醒牧师变种。她有自己的职业伦理、机构立场和选择，不成为林序固定队友。她与林序会因救援成本、伤员优先级和冒险者医疗制度合作或冲突。

### 赵峥

经验丰富、天赋普通的战士变种冒险者。熟悉低级地下城的真实死亡率，代表职业冒险者的现实经验。他与林序之间是人情、交易和有限信任，不是永久队长与队员关系。

### 阿铆

侏儒工匠。理解现实结构和异界材料，是长期交易对象与技术合作者，但拥有自己的族群、订单和利益，不加入林序固定团队。

### 叶观澜

国家裂缝管理系统的调查人员。她会保护林序免受非法组织侵害，也会依法扣押、审查和限制他。双方是制度内的长期博弈关系。

### 沈阙

曜石集团创始人、高阶冒险者。相信高风险资源应由少数有能力承担后果的人控制。他是重要对手，但不承担全书所有阴谋；国家、财团、教会、法师和其他候选者都有独立利益。

### 魔法女神／真理编织者

魔网的维护者或持有者之一，与人类起源和林序异常有关。她不是免费外挂后台，也不在前十篇解释全部目的。

## 十、位面战争长期真相

- 随机裂缝测试个体适应能力。
- 限制人数的地下城筛选职业者与候选文明。
- 稳定传送门建立资源和军事投送网络。
- 永恒裂缝形成位面领地与边境。
- 15级冒险者收到正式“位面战争资格协议”，确认此前所有训练都是战争前菜。
- 16—20级参与跨位面战争、神权代理和候选者猎杀。
- 位面战争的最高收益不是土地，而是有限的登神名额与神职。
- 神位对应具体规则、责任和束缚，成神并不等于自由。

公众早已听过战争和登神传闻，国家与教会掌握部分证据；15级的区别在于获得不可否认的系统确认，而不是第一次听说。

## 十二、前十篇结束状态

第300章不是大结局，而是第一阶段终点：

- 林序成为15级S级／传说门槛冒险者。
- 主职业仍是【游侠·陷阱专家】，副职业仍是【行商人】，不会正常施法。
- 他拥有跨位面装备体系、贸易信用、安全屋和多条撤退路线，但没有固定公会或军队。
- 国家、教会、法师组织、财团、异族与诸神代理都已将他列入战略名单。
- 他正式确认位面战争和登神名额存在。
- 地球社会仍然分裂，三座失城成为永久位面边境。
- 魔法女神的目的、人类的真实创造实验、登神名额数量和战争规则仍未完全揭晓。
- 下一阶段从“地下城冒险”进入“位面战争资格争夺”，仍以林序个人生存与选择为视角。

前十篇完成的是入场，不是终局。
