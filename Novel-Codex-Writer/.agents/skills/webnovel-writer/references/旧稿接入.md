# 旧稿接入

## 原则

- 先复制旧稿到当前已登记作品目录内的独立候选位置，不覆盖现有正文。
- 按文件名和 Markdown 标题识别章节；同一章有多个候选时停止，让作者选择。
- 旧版正文、备份和 `.trash` 默认不进入当前写作上下文。
- 先生成接入清单：章节号、路径、revision、缺章、重复章和无法识别的文件。

## 确认后操作

1. 作者确认正文候选与章节顺序。
2. 将确认版本写入 `正文/`；写入前保存现有版本到 `.history/`。
3. 旧审查、提交和 patch 只作为历史证据，不自动视为与接入正文匹配。
4. 重新生成任务书和审查报告，再按章节最终化流程建立新 manifest。
