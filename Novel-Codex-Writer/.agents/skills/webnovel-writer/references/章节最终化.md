# 章节最终化

`chapter_result` 代表一章已经完成，不是普通记忆建议。最终化前必须同时满足：

- 唯一且已确认的本章细纲；
- 当前 `本章写作任务书.md` 及其来源 metadata 未失效；
- 唯一正文文件与 `chapter_revision` 一致；
- 审查报告明确记录同一正文 revision，且没有未处理的 S1/S2；
- 章节提交记录明确记录同一正文 revision；
- schema v2 patch 的 `source_revisions` 包含上述文件并全部匹配。

应用 patch 后生成 `章节提交/第XXX章_finalization.json`。manifest 绑定细纲、任务书、正文、审查、提交和 patch 的 SHA-256。任一来源变化后状态必须显示 stale，旧审查、提交和 patch 不再作为下一章依据；重新检查并再次确认，不自动改写正文。

同章多个旧 patch 必须由作者指定唯一 `chapter_result`。分类信息单独保存在 `章节提交/compat/patch_classifications.json`；旧版 `章节提交/patch_classifications.json` 继续只读兼容，旧 patch 文件保持原样。
