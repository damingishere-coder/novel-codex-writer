# 章节提交规范

章节 commit 是每章写完后的结构化记录，用于快速了解这一章“改变了什么”。

## 必须包含

- 章节号
- 章节标题
- 本章一句话摘要
- 剧情推进
- 人物状态变化
- 关系变化
- 伏笔新增、推进或兑现
- 设定新增或确认
- 不可违背事实
- 下一章钩子
- 对应 memory_patch 的 `patch_id`、一句话摘要和章末状态

## 写法要求

- 写变化，不写流水账。
- 写会影响后续创作的信息。
- 不要复制整章正文。
- 不确定的信息标注“待确认”，不要写成铁事实。
- memory_patch 使用 `references/记忆补丁格式.md` 的结构，不把自由格式“新增/更新/移除”列表交给自动脚本猜测。
