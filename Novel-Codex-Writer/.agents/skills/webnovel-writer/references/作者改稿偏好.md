# 作者改稿偏好

作者对正文的修改可以帮助下一次写得更贴合，但不能把一次修改直接升级为永久规则。

## 候选提取

- 只比较同一正文的相邻 revision，记录可观察变化，例如句长、对白密度、视角、解释量和禁用表达。
- 每条候选附来源章节、前后 revision、简短证据和适用范围。
- 不推断作者身份、情绪、政治立场等无关属性。

## 确认门槛

1. 在网页或回复中向作者展示候选，不自动写入规范。
2. 只有作者明确确认后，才写入 `写作规范/作者编辑画像.md`。
3. 记录确认时间和来源；相互冲突的偏好并列为候选，重新确认后再替换。
4. 作者画像只能影响风格选择，不能覆盖总纲、细纲、不可违背事实或章节 revision 门禁。
